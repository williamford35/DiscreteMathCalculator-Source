As you work through the following steps, note that the integers displayed will differ from those in this document since some computations involve random numbers. The decrypted result will remain 1862474446406222365543.

1. To encrypt a message, the message must be converted into an integer. We will use the following encoding:
'0' ⇔ 00, '1'⇔ 01, ..., '9'⇔ 09, 'A'⇔ 10, 'B'⇔ 11, ..., 'Z'⇔ 35, 'a'⇔ 36, 'b'⇔ 37, ..., 'z'⇔ 61, ' '(blank)⇔ 62
Using this encoding, the message "I like Math" is represented by the integer 1862474446406222365543.
2. Generate two 64-bit random prime numbers p and q. Then form the product n = pq. Do this by generating one random 64-bit integer, executing →a, generating a second random 64-bit integer, executing →b and then executing *. Here we got
p = 10498885118990589977, q = 14473981811441518427, and n = 151960672252683821250247341461447006179
Save n in memory register 1 by pressing MS1.



3. Use the phi(a*b) button to compute the value of the totient function t = φ(n) = (p-1)*(q-1) = 151960672252683821225274474531014897776. Copy t to both n and a using →n and →a.
   


4. Execute coprime(a). This computes e, an integer in Zn that is relatively prime to t = φ(n). Copy e to both a and b using ->a and ->b. We have now computed the public key (e,n).
   



5. We can now compute d such that ed   ≡ 1 (mod φ(n)) by pressing inv(a) mod(n). Copy d to memory register 2 by pressing MS2. We now have the private key (d, n).
   



6. We are now ready to encrypt the message M = 1862474446406222365543. Enter M into a, execute MR1 and copy the n to text field n using ->n. Encrypt M by computing
C = Me (mod n)
Since M is in a, e is in b, and n is loaded, execute ^ (mod n) to get the encrypted message C = 105010901795307998633963878015458608293.
   



7. To decrypt the message, we must compute
Cd (mod n)
where (d, n) is the private key. Copy C to a by executing ->a, followed by MR2 and ->b and execute ^(mod n).
   


   

The result is the original message M = 1862474446406222365543. By inverting our string -> integer encoding, we get the original message
